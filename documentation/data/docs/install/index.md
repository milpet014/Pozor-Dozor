# Inštalácia a spustenie

Táto časť dokumentácie vysvetľuje, ako aplikáciu **Pozor Dozor** stiahnuť, nainštalovať alebo spustiť na podporovaných operačných systémoch.

Aplikácia je distribuovaná cez **GitHub Releases**, kde sú pripravené hotové súbory pre bežné používanie. Používateľ preto nemusí zostavovať zdrojový kód ani nastavovať vývojové prostredie.

V tejto kapitole nájdete postup stiahnutia aplikácie, samostatný návod pre **Windows**, samostatný návod pre **Linux**, informácie o prvom spustení, aktualizácii aplikácie a umiestnení dátových súborov.

Pre bežného používateľa je najdôležitejšie stiahnuť správny súbor podľa operačného systému:

| Operačný systém | Odporúčaný typ súboru |
|---|---|
| **Windows** | inštalačný súbor `.exe` |
| **Linux** | spustiteľný súbor `.AppImage` |

Súbory označené ako **Source code** sú určené najmä pre vývojárov. Ak chcete aplikáciu iba používať, tieto súbory nie je potrebné sťahovať.
