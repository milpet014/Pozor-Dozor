# Inštalácia vo Windowse

Táto stránka opisuje základný postup inštalácie aplikácie **Pozor Dozor** v operačnom systéme Windows.

Aplikácia je pre Windows distribuovaná ako inštalačný súbor s príponou `.exe`. Bežný používateľ preto nemusí nič kompilovať ani nastavovať vo vývojovom prostredí.

---

## Stiahnutie inštalátora

Pred inštaláciou je potrebné stiahnuť aktuálnu verziu aplikácie zo stránky **GitHub Releases**.

!!! info "Odporúčaný súbor pre Windows"

    Pre Windows si stiahnite súbor s príponou:

    ```text
    .exe
    ```

    Súbory označené ako **Source code** nie sú určené na bežnú inštaláciu aplikácie.

---

## Spustenie inštalátora

Po stiahnutí inštalačného súboru ho spustite dvojklikom.

!!! example "Postup inštalácie"

    1. Otvorte priečinok, do ktorého bol inštalátor stiahnutý.
    2. Dvojklikom spustite súbor aplikácie s príponou `.exe`.
    3. Ak sa zobrazí bezpečnostné upozornenie systému Windows, potvrďte spustenie iba vtedy, ak bol súbor stiahnutý z oficiálneho GitHub repozitára projektu.
    4. Pokračujte podľa pokynov inštalátora.
    5. Po dokončení inštalácie spustite aplikáciu **Pozor Dozor**.

!!! warning "Bezpečnostné upozornenie Windows"

    Windows môže pri prvom spustení zobraziť upozornenie, pretože aplikácia nemusí byť podpísaná certifikátom od veľkej softvérovej firmy.

    Ak ste inštalátor stiahli z oficiálnej stránky projektu, môžete pokračovať v spustení. Ak súbor pochádza z neznámeho zdroja, neinštalujte ho.

---

## Prvé spustenie aplikácie

Po úspešnej inštalácii môžete aplikáciu spustiť zo zoznamu aplikácií, zo zástupcu alebo priamo po dokončení inštalácie.

Pri prvom spustení aplikácia zobrazí úvodného sprievodcu, ktorý vysvetlí základné použitie aplikácie a ponúkne nastavenie cloudovej zálohy.

!!! tip "Cloud nie je povinný"

    Aplikáciu je možné používať aj bez cloudovej zálohy.

    Ak cloud nepovolíte, všetky údaje sa budú ukladať iba lokálne v počítači.
